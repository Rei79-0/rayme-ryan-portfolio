# Rayme Ryan Portfolio

## Files
- `index.html` — page structure and portfolio content
- `style.css` — custom styling and responsive layouts
- `script.js` — project details, filters, navigation, theme toggle, contact form, and page interactions
- `tailwind.config.js` — separate Tailwind CDN configuration

## Run locally
Keep all four files in the same folder and open `index.html` in a browser.
Tailwind is loaded from its CDN, so an internet connection is needed for that dependency.
The portfolio's visual styling is currently handled by `style.css`; Tailwind is included as requested but no Tailwind utility classes are required by the existing markup.

## Notes
- The contact form prepares a message in the visitor's email application; it does not send or store messages on a server.
- Personal contact details are included as provided in the resume.
